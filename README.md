# Production Systems I: WhyNot Case Study

Production Systems I course project, B.E. Industrial Engineering, Lebanese
American University

## Overview
An analysis of production data for "WhyNot" to find areas for improvement,
recommend changes to management, and compare lot sizing methods to reduce
production costs.

## What I did
- **Data analysis:** analyzed company data to identify key areas for
  improvement, then presented recommendations to management that led to a
  **10% increase in overall productivity**
- **Lot sizing comparison:** investigated production system techniques and
  found the **Silver-Meal heuristic** to be the most efficient lot sizing
  method, with cost savings of **$10,000 per month**

## Methods
- Production system analysis and productivity improvement
- Lot sizing methods, including Silver-Meal
